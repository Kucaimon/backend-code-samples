# Ananda — backend code review sample

## Что внутри

- `early_checkin_decision_excerpt.py` — выбранный обработчик callback-кнопок менеджера из Telegram staff bot.
- `early_checkin_flow_acceptance.py` — исходный статический acceptance-check из патча от 19.10.2026.

## Что демонстрирует фрагмент

- асинхронный обработчик Telegram callback через aiogram;
- проверку прав активного менеджера;
- асинхронные запросы к БД через SQLAlchemy;
- блокировку строк через `SELECT ... FOR UPDATE` при обработке решения;
- проверки типа уведомления, статуса заявки и актуальности запрошенного времени;
- защиту от повторного/устаревшего решения;
- обновление контекста диалога;
- постановку ответа гостю в очередь уведомлений;
- запись бизнес-события через telemetry helper;
- обработку ошибок данных и БД.

## Границы примера и честные оговорки

Это фрагмент реального Python backend-кода Ananda, а не самостоятельный репозиторий и не NestJS-проект. Он показывает конкретный сценарий Telegram-бота и работу с SQLAlchemy. В архиве-патче отсутствуют определения моделей, `SessionFactory`, очередь уведомлений и часть приложения, поэтому модуль нельзя запустить отдельно.

Acceptance-check — статический тест, который читает `app/bots/staff.py` и `app/bots/guest.py` из полного проекта. В этой подборке полного приложения нет, поэтому тест не предназначен для автономного запуска.

В исходном обработчике не видно явного `session.commit()`. Без реализации `SessionFactory` и `enqueue_guest_notification` нельзя независимо подтвердить, где именно фиксируется транзакция. Этот вопрос стоит проверить по полному репозиторию, прежде чем делать заявления об атомарности операции.

Тексты сообщений гостю обобщены, чтобы не раскрывать конкретные инструкции объекта размещения. Идентификаторы, токены, `.env`, серверные пути, deployment-скрипт, демо-ссылки и конфигурации в подборку не включены.

## Конфиденциальность

Фрагмент взят из клиентского проекта. Перед передачей третьей стороне убедитесь, что договорённости с клиентом и NDA разрешают показывать этот код даже в обезличенном виде. Если такого разрешения нет, не отправляйте исходник; можно вместо него описать реализованную задачу без раскрытия кода.
